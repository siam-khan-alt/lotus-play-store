# Lotus Play Store

A React + Vite app for browsing and downloading apps with Firebase auth.

**Live:** [imaginative-cendol-d33611.netlify.app]

## Features
- Email/Password & Google SignIn
- Smooth page transitions
- Toast notifications
- Responsive design

## Packages
React, React Router, Firebase, Tailwind CSS, DaisyUI, Framer Motion, React Toastify, Swiper
